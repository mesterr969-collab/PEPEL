# Contributing

1. Open an issue to describe the problem or the proposed change.
2. Never include Steam passwords, Player Tokens, pairing JSON, or personal user-data files.
3. Keep pull requests focused and explain how they were tested.
4. Run `npm run check` before submitting.
5. Network-dependent changes should document their API source, failure handling, and an offline/error state.
6. Do not claim a Windows/Rust+ flow was tested unless it was actually tested on Windows against a real server.
