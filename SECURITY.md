# Security policy

## Reporting

Please do not post working Steam credentials, Rust+ Player Tokens, pairing JSON, auth files, or private server IPs in public issues.

Until a private contact channel is configured, do not publish exploitable security details publicly. The repository owner can enable GitHub private vulnerability reporting in **Settings → Security** and link it here.

## User data

Before sharing logs/screenshots, review and redact account identifiers, tokens, local paths, and private server information.
