# PEPEL 2.4.7 — Windows x64

## В этой версии
- Удалены интерактивные метки на карте; просмотр карты и обновление оставлены в «Стол → Заметки».
- Удалён раздел «Расход ТК».
- Оставлены каталог серверов, слежка, Steam/Rust+, рейд-калькулятор, фото базы, плавильни, чек-лист, электрические схемы, справочник монументов и настройки.
- Сохранена возможность настроить автообновление через публичный GitHub Releases.

## Установка
Распакуй архив полностью и запусти `PEPEL.exe` внутри папки. Не запускай EXE непосредственно из ZIP.

## Известные ограничения
Сетевые источники, Rust+ и автоматическое обновление требуют отдельной проверки на целевой Windows-машине.
