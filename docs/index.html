FAQ

Перед запуском

Как установить ПЕПЕЛ?

Скачай ZIP из Releases, распакуй весь архив в отдельную папку и запусти PEPEL.exe внутри. Не перемещай один EXE отдельно от файлов приложения.

Почему Windows показывает предупреждение?

У сборки может не быть цифровой подписи издателя. Проверяй, что скачиваешь её из официального релиза проекта; не отключай защиту Windows без необходимости.

Почему Rust+ или серверы могут быть недоступны?

Эти разделы зависят от сети, сторонних API и настроек сервера. Перед выпуском новой версии сетевые сценарии необходимо проверить на Windows.

Это официальный продукт Rust?

Нет. ПЕПЕЛ — независимый фанатский проект и не связан с Facepunch Studios.
