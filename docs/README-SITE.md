# PEPEL website (GitHub Pages)

The static landing page is located in `docs/index.html`.

1. Publish a release and attach `PEPEL-2.4.7-Windows-x64.zip`.
2. In repository Settings → Pages select Deploy from a branch, branch `main`, folder `/docs`.
3. The landing page links to the latest GitHub Release. The Windows download asset link works after the release asset is uploaded.

No build step or external frontend library is required.
